# Charith Liyanaarachchi — Portfolio

React + Vite portfolio in the Global Exceed / TAPVI card palette (deep black-violet, violet, amber).

## Run locally
```bash
npm install
npm run dev        # http://localhost:5173
```

## Build for hosting
```bash
npm run build      # outputs static site to /dist
```
Upload the contents of `dist/` to any static host (Netlify, Vercel, cPanel, GitHub Pages).
A pre-built `dist/` is already included.

## Editing content
All text, roles, ventures, experience and certifications live in `src/data.js`.
Logos and portraits are in `src/assets/`. Colours are CSS variables at the top of `src/styles.css`.
